# Reybraztech — Status do Projeto

**Última Atualização:** 26/04/2026  
**Versão:** 1.0

---

## 📋 O que o Projeto Faz

Sistema de vendas e gestão de acessos para conteúdo IPTV (canais de TV, filmes, séries).

### Fluxo Principal

```
Cliente se cadastra → Escolhe plano → Paga (Mercado Pago ou InfinityPay)
        ↓
   Libera login/senha de acesso ao app
        ↓
   Dashboard mostra: plano, dias restantes, credenciais
```

---

## 🏗️ Stack Tecnológica

| Camada | Tecnologia |
|--------|------------|
| **Frontend** | React 19 + Vite + TailwindCSS |
| **Backend** | Express.js + TypeScript |
| **Banco** | PostgreSQL (Supabase) |
| **Pagamentos** | Mercado Pago + InfinityPay |
| **Notificações** | Telegram Bot + WhatsApp (SendPulse) |
| **Infra** | Vercel (frontend) + Render (backend) |
| **Monitoramento** | Sentry + Winston logs |
